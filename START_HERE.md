## 🚀 Быстрый старт (3 минуты)

### Шаг 1: Получите API ключ
1. Перейдите на https://platform.deepseek.com/
2. Зарегистрируйтесь
3. Создайте API ключ

### Шаг 2: Настройте приложение
Добавьте в ваш `.env` файл:

```bash
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

### Шаг 3: Проверьте работу
```bash

rails ai_reviews:deepseek_status

# Протестировать (генерирует тестовый SEO-текст)
rails ai_reviews:test_deepseek
```

### Шаг 4: Включите для SEO (экономия 90%!)
```bash

```
