# API для генерации SEO текстов для страниц автомобилей

## Описание

Endpoint для автоматической генерации SEO-оптимизированных структурированных HTML-текстов для страниц подбора шин по автомобилям (например, `/shiny/auto/toyota/camry/`).

Генерирует уникальные HTML-тексты на русском и украинском языках с учетом:
- Марки и модели автомобиля
- Типичных размеров шин
- Сезонности (летние, зимние, всесезонные)
- Популярных брендов
- Рекомендаций по подбору
- Автоматическая вставка ссылок на размеры и страницу автомобиля
- HTML-структура с заголовками H2, H3, H4
- Списки и выделения для лучшей читаемости

## Endpoint

```
GET /api/v1/car_seo_text
```

## Параметры запроса

### Обязательные параметры

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `brand` | string | Марка автомобиля | `toyota` |
| `model` | string | Модель автомобиля | `camry` |
| `language` | string | Язык текста (`ru` или `ua`) | `ru` |
| `typical_sizes` | string | Размеры шин через запятую | `215/55R17,215/60R16` |

### Опциональные параметры

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `generation` | string | Поколение автомобиля | `XV70` |
| `production_years` | string | Годы выпуска | `2017-2023` |
| `body_type` | string | Тип кузова | `седан` |
| `car_class` | string | Класс автомобиля | `D` |

## Примеры запросов

### Базовый запрос (русский язык)

```bash
curl "http://localhost:3000/api/v1/car_seo_text?brand=toyota&model=camry&language=ru&typical_sizes=215/55R17,215/60R16"
```

### Полный запрос с опциональными параметрами

```bash
curl "http://localhost:3000/api/v1/car_seo_text?brand=toyota&model=camry&language=ru&typical_sizes=215/55R17,215/60R16&body_type=седан&car_class=D&generation=XV70&production_years=2017-2023"
```

### Запрос на украинском языке

```bash
curl "http://localhost:3000/api/v1/car_seo_text?brand=toyota&model=camry&language=ua&typical_sizes=215/55R17,215/60R16"
```

## Формат ответа

### Успешный ответ (200 OK)

```json
{
  "text": "<h2>Шины для Toyota Camry</h2><p>Сгенерированный HTML SEO текст с заголовками, ссылками и списками...</p>",
  "brand": "toyota",
  "model": "camry",
  "language": "ru",
  "generated_at": "2025-11-10T12:58:29.376Z"
}
```

**Примечание:** Поле `text` содержит полноценный HTML-код с:
- Заголовками H2, H3, H4
- Ссылками на размеры шин (`<a href="/shiny/w-215/h-55/r-17/">`)
- Ссылками на страницу автомобиля
- Маркированными и нумерованными списками
- Выделениями ключевых слов (`<strong>`)
- Встроенными стилями CSS

### Ошибка валидации (400 Bad Request)

```json
{
  "error": "Brand is required"
}
```

### Ошибка генерации (422 Unprocessable Entity)

```json
{
  "error": "Failed to generate text"
}
```

## Структура генерируемого HTML-текста

Сгенерированный текст имеет следующую HTML-структуру:

1. **H2: Основной заголовок**
   ```html
   <h2>Шины для [Марка] [Модель]</h2>
   ```
   - Упоминание "шины для [Марка] [Модель]"
   - Указание типа кузова (если доступно)
   - Подчеркивание подбора по заводским параметрам

2. **H3: Типичные размеры шин**
   ```html
   <h3>Типичные размеры шин для [Марка] [Модель]</h3>
   <ul>
     <li><a href="/shiny/w-215/h-55/r-17/">шины 215/55R17</a> - описание</li>
     <li><a href="/shiny/w-215/h-60/r-16/">шины 215/60R16</a> - описание</li>
   </ul>
   ```

3. **H3: Сезонность шин**
   ```html
   <h3>Сезонность шин для [Марка] [Модель]</h3>
   <h4>Летние шины</h4>
   <p>Описание летних шин...</p>
   <h4>Зимние шины</h4>
   <p>Описание зимних шин...</p>
   <h4>Всесезонные шины</h4>
   <p>Описание всесезонных шин...</p>
   ```

4. **H3: Ключевые параметры выбора**
   ```html
   <h3>Ключевые параметры выбора шин</h3>
   <ol>
     <li><strong>Индекс нагрузки</strong> - описание</li>
     <li><strong>Индекс скорости</strong> - описание</li>
     <li><strong>Рисунок протектора</strong> - описание</li>
   </ol>
   ```

5. **H3: Преимущества ProKoleso**
   ```html
   <h3>Преимущества покупки в ProKoleso</h3>
   <ul>
     <li>Широкий ассортимент</li>
     <li>Гарантия качества</li>
     <li>Профессиональная консультация</li>
     <li>Доставка и удобные формы оплаты</li>
   </ul>
   ```

6. **Заключение с призывом к действию**
   - Ссылки на все размеры: `<a href="/shiny/w-215/h-55/r-17/">шины 215/55R17 для [Марка] [Модель]</a>`
   - Ключевые фразы: "Купить шины на [Марка] [Модель]", "Купить резину на [Марка] [Модель]"
   - Призыв к действию с консультацией

## Ключевые слова

В тексте обязательно используются следующие ключевые фразы (по одному разу каждая):
- "Купить шины на [Марка] [Модель]"
- "Купить резину на [Марка] [Модель]"

## Особенности генерации

- **Объем текста**: 2000-3500 знаков (для популярных моделей до 4000)
- **Формат**: Структурированный HTML с заголовками H2, H3, H4
- **Тошнотность**: не более 20%
- **Водность**: не более 60%
- **Формат ссылок**: Все ссылки на размеры используют формат `/shiny/w-215/h-55/r-17/`
- **Автоматические ссылки**:
  - На страницу автомобиля: `/shiny/auto/[brand]/[model]/`
  - На размеры: `/shiny/w-[width]/h-[height]/r-[radius]/`
  - На размеры с брендом в тексте
- **HTML-элементы**:
  - Заголовки: `<h2>`, `<h3>`, `<h4>`
  - Списки: `<ul>`, `<ol>`, `<li>`
  - Выделения: `<strong>`
  - Параграфы: `<p>`
  - Ссылки: `<a href="...">`
  - Встроенные стили CSS
- **Стиль**: Естественный, технический, без рекламных штампов
- **Местоимения**: Не используются личные местоимения в единственном числе
- **Безличные конструкции**: "Шины характеризуются...", "Модель отличается..."

## Примечания

1. Если параметры `body_type` и `car_class` не указаны, AI попытается определить их автоматически на основе марки и модели
2. Для украинского языка автоматически переводятся типы кузова
3. Каждая генерация создает уникальный текст благодаря использованию AI

## Кэширование

Рекомендуется кэшировать результаты генерации для одинаковых параметров, чтобы:
- Снизить нагрузку на AI API
- Ускорить отдачу контента
- Сэкономить на запросах к AI

Пример кэширования в Rails:

```ruby
cache_key = "car_seo_text:#{brand}:#{model}:#{language}:#{typical_sizes.join('-')}"
Rails.cache.fetch(cache_key, expires_in: 30.days) do
  # вызов генерации текста
end
```

## Ограничения

- Максимальное время генерации: ~30 секунд
- Timeout запроса: 120 секунд
- Рекомендуемое количество размеров: 2-4 (для оптимального качества текста)

## Проверка целостности текста

API автоматически проверяет, что сгенерированный текст:
- Завершен корректно (заканчивается тегом `</p>`)
- Содержит обязательную заключительную фразу (CTA)
- Имеет сбалансированные HTML-теги (все открывающие теги имеют соответствующие закрывающие)

Если текст обрезан или неполный, API вернет ошибку:
```json
{
  "error": "Generated text is incomplete. Please try again or reduce text length requirements."
}
```

В этом случае рекомендуется:
1. Повторить запрос (AI может сгенерировать более короткий вариант)
2. Уменьшить количество размеров в параметре `typical_sizes`
3. Проверить логи сервера для деталей
