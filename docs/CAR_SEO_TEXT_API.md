# API для генерации SEO текстов для страниц автомобилей

## Описание

Endpoint для автоматической генерации SEO-оптимизированных текстов для страниц подбора шин по автомобилям (например, `/shiny/auto/toyota/camry/`).

Генерирует уникальные тексты на русском и украинском языках с учетом:
- Марки и модели автомобиля
- Типичных размеров шин
- Сезонности
- Популярных брендов
- Рекомендаций по подбору

## Endpoint

```
GET /api/v1/car_seo_text
```

## Параметры запроса

### Обязательные параметры

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `brand` | string | Марка автомобиля | `toyota` |
| `model` | string | Модель автомобиля | `camry` |
| `language` | string | Язык текста (`ru` или `ua`) | `ru` |
| `typical_sizes` | string | Размеры шин через запятую | `215/55R17,215/60R16` |

### Опциональные параметры

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `generation` | string | Поколение автомобиля | `XV70` |
| `production_years` | string | Годы выпуска | `2017-2023` |
| `body_type` | string | Тип кузова | `седан` |
| `car_class` | string | Класс автомобиля | `D` |

## Примеры запросов

### Базовый запрос (русский язык)

```bash
curl "http://localhost:3000/api/v1/car_seo_text?brand=toyota&model=camry&language=ru&typical_sizes=215/55R17,215/60R16"
```

### Полный запрос с опциональными параметрами

```bash
curl "http://localhost:3000/api/v1/car_seo_text?brand=toyota&model=camry&language=ru&typical_sizes=215/55R17,215/60R16&body_type=седан&car_class=D&generation=XV70&production_years=2017-2023"
```

### Запрос на украинском языке

```bash
curl "http://localhost:3000/api/v1/car_seo_text?brand=toyota&model=camry&language=ua&typical_sizes=215/55R17,215/60R16"
```

## Формат ответа

### Успешный ответ (200 OK)

```json
{
  "text": "Сгенерированный SEO текст...",
  "brand": "toyota",
  "model": "camry",
  "language": "ru",
  "generated_at": "2025-11-10T12:58:29.376Z"
}
```

### Ошибка валидации (400 Bad Request)

```json
{
  "error": "Brand is required"
}
```

### Ошибка генерации (422 Unprocessable Entity)

```json
{
  "error": "Failed to generate text"
}
```

## Структура генерируемого текста

Сгенерированный текст включает следующие разделы:

1. **Вступление (2-3 предложения)**
   - Упоминание "шины для [Марка] [Модель]"
   - Указание типа кузова (если доступно)
   - Подчеркивание подбора по заводским параметрам

2. **Основная часть (3-4 абзаца)**
   - Описание типичных размеров шин
   - Варианты сезонности (летние, зимние, всесезонные)
   - Популярные бренды
   - Советы по выбору (индексы нагрузки/скорости, давление)

3. **Преимущества подбора на ProKoleso (2-3 предложения)**
   - Удобные фильтры
   - Доставка и формы оплаты
   - Профессиональная консультация
   - Проверенные бренды с гарантией

4. **Заключение с призывом к действию (1-2 предложения)**
   - Призыв выбрать шины в каталоге
   - Призыв оформить заказ онлайн

## Ключевые слова

В тексте обязательно используются следующие ключевые фразы (по одному разу каждая):
- "Купить шины на [Марка] [Модель]"
- "Купить резину на [Марка] [Модель]"

## Особенности генерации

- **Объем текста**: 1500-2500 знаков (для популярных моделей до 3000)
- **Тошнотность**: не более 20%
- **Водность**: не более 60%
- **Формат ссылок**: Все ссылки на размеры используют формат `/shiny/w-215/h-55/r-17/`
- **Стиль**: Естественный, без рекламных штампов
- **Местоимения**: Не используются личные местоимения в единственном числе

## Примечания

1. Если параметры `body_type` и `car_class` не указаны, AI попытается определить их автоматически на основе марки и модели
2. Для украинского языка автоматически переводятся типы кузова
3. Каждая генерация создает уникальный текст благодаря использованию AI

## Кэширование

Рекомендуется кэшировать результаты генерации для одинаковых параметров, чтобы:
- Снизить нагрузку на AI API
- Ускорить отдачу контента
- Сэкономить на запросах к AI

Пример кэширования в Rails:

```ruby
cache_key = "car_seo_text:#{brand}:#{model}:#{language}:#{typical_sizes.join('-')}"
Rails.cache.fetch(cache_key, expires_in: 30.days) do
  # вызов генерации текста
end
```

## Ограничения

- Максимальное время генерации: ~30 секунд
- Timeout запроса: 120 секунд
- Рекомендуемое количество размеров: 2-4 (для оптимального качества текста)
