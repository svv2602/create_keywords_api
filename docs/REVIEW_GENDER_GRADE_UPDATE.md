# Обновление системы генерации отзывов: пол и оценки

## 📋 Проблема

Пользователи-модераторы сообщили о следующих проблемах с генерируемыми отзывами:

### 1️⃣ Несоответствие имени и пола
**Проблема**: Имя не соответствует роду автора в тексте.
- "Элизабет купил..." (женское имя + мужской род)
- "Василий поставила..." (мужское имя + женский род)

**Причина**: Система генерировала пол и имя **ПОСЛЕ** того, как AI создавал текст отзыва.

### 2️⃣ Несоответствие оценки и текста
**Проблема**: Оценка (1-5) не соответствует тексту отзыва.
- "Все отлично, рекомендую" + оценка 2
- "Ужасный опыт" + оценка 5

**Причина**: Итоговая оценка вычислялась **ПОСЛЕ** генерации текста, и AI не знал какой тональности должен быть отзыв.

---

## ✅ Решение

### Архитектурное изменение

**ДО** (старая логика):
```
1. Генерация базового текста отзыва
2. AI обработка текста (без знания пола и оценки)
3. Определение пола из текста
4. Генерация имени на основе определенного пола
5. Вычисление итоговой оценки
```

**ПОСЛЕ** (новая логика):
```
1. Генерация пола и имени
2. Вычисление итоговой оценки и оценок по характеристикам
3. Генерация базового текста отзыва
4. AI обработка с учетом пола и оценок ✨
```

### 2. Файл: `app/services/universal_review_processor.rb`

#### Обновление `build_context_instructions`:

Добавлены инструкции для AI по полу автора:

```ruby
# Инструкции по полу автора
if context[:gender]
  if context[:gender] == "женщина"
    instructions += "- ВАЖНО: Пиши от лица женщины, используй женский род (купила, поставила, довольна, рада, рекомендую)\n"
  else
    instructions += "- ВАЖНО: Пиши от лица мужчины, используй мужской род (купил, поставил, доволен, рад, рекомендую)\n"
  end
end

# Инструкции по оценкам
if context[:grade] && context[:grade] > 0
  instructions += build_grade_instructions(context[:grade], context[:array_average])
end
```

#### Новый метод `build_grade_instructions`:

Умная генерация инструкций на основе оценки:

```ruby
def build_grade_instructions(grade, array_average)
  # Интерпретирует оценку:
  # 4.5-5.0  → "восторженный, крайне позитивный"
  # 4.0-4.5  → "очень положительный, с большим энтузиазмом"
  # 3.5-4.0  → "положительный, доволен покупкой"
  # 3.0-3.5  → "в целом нейтральный, со средними впечатлениями"
  # 2.5-3.0  → "скорее нейтральный с легкими замечаниями"
  # 2.0-2.5  → "скорее недоволен, есть проблемы"
  # 1.5-2.0  → "недоволен покупкой, много замечаний"
  # <1.5     → "крайне негативный, разочарован"

  # Анализирует разброс оценок по характеристикам
  # Если разброс > 2.0 → указывает на сильные и слабые стороны
  # Добавляет предупреждение о согласованности
end
```

## 📊 Примеры работы

### Пример 1: Женщина с высокой оценкой (4.5/5)

**Контекст**:
- Пол: женщина
- Оценка: 4.5/5
- Оценки по характеристикам: [4.5, 5.0, 4.0, 4.5]

**Инструкции AI**:
```
- Обязательно используй бренд Michelin в отзыве
- Обязательно упомяни модель Pilot Sport 4 в отзыве
- ВАЖНО: Пиши от лица женщины, используй женский род (купила, поставила, довольна, рада, рекомендую)
- КРИТИЧЕСКИ ВАЖНО: Итоговая оценка 4.5 из 5 - текст должен быть восторженный, крайне позитивный
- Средняя оценка по характеристикам: 4.5/5
- ЗАПРЕЩЕНО: Писать восторженный текст при низкой оценке или критический текст при высокой оценке!
```

**Результат**: AI сгенерирует текст от лица женщины с восторженным тоном.

### Пример 2: Мужчина с низкой оценкой (2.0/5)

**Контекст**:
- Пол: мужчина
- Оценка: 2.0/5
- Оценки по характеристикам: [2.0, 1.5, 2.5, 2.0]

**Инструкции AI**:
```
- Обязательно используй бренд Yokohama в отзыве
- ВАЖНО: Пиши от лица мужчины, используй мужской род (купил, поставил, доволен, рад, рекомендую)
- КРИТИЧЕСКИ ВАЖНО: Итоговая оценка 2.0 из 5 - текст должен быть скорее недоволен, есть проблемы
- Средняя оценка по характеристикам: 2.0/5
- ЗАПРЕЩЕНО: Писать восторженный текст при низкой оценке или критический текст при высокой оценке!
```

**Результат**: AI сгенерирует критический текст от лица мужчины.

### Пример 3: Оценка с большим разбросом

**Контекст**:
- Оценка: 3.5/5
- Оценки по характеристикам: [5.0, 3.0, 2.5, 4.0, 3.5, 3.5] (разброс: 2.5-5.0)

**Инструкции AI**:
```
- КРИТИЧЕСКИ ВАЖНО: Итоговая оценка 3.5 из 5 - текст должен быть положительный, доволен покупкой
- Средняя оценка по характеристикам: 3.6/5
- ВАЖНО: Есть разброс в оценках (от 2.5 до 5.0) - можешь упомянуть как сильные, так и слабые стороны
```

**Результат**: AI создаст сбалансированный отзыв с упоминанием плюсов и минусов.

## 📝 Дополнительная информация

### Структура оценок

**Летние шины**: 4 характеристики
- Управляемость (курсовая устойчивость, маневренность)
- Сцепление с дорогой
- Износостойкость
- Комфорт

**Зимние/всесезонные**: 6 характеристик
- Управляемость
- Сцепление на снегу
- Сцепление на льду
- Износостойкость
- Комфорт
- Торможение

### Формирование итоговой оценки

```ruby
grade = (array_average.sum.to_f / array_average.size * 2).round / 2.0
# Округляется до 0.5 (например: 3.7 → 3.5, 4.2 → 4.0)
```
