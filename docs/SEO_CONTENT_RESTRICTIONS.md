# Ограничения контента в SEO генераторе для шин

## Проблема

При генерации SEO текстов для моделей шин LLM добавлял от себя информацию, которая не соответствует реальности:
- Условия доставки (сроки, стоимость, способы)
- Гарантийные обязательства
- Акции и специальные предложения
- Цены на товары
- Способы оплаты
- Сервисные услуги (шиномонтаж, балансировка)
- Наличие товара на складе

## Решение

### 1. Явные запреты в промпте

В промпт добавлены строгие инструкции о запрещённых темах:

**Запрещено упоминать:**
- доставк*, гарант*, акци*, скид*, цен*, оплат*
- шиномонтаж*, балансир*, консультант*, консультаци*
- по телефону, через корзину, звоните и т.д.

**Разрешено писать только о:**
- Технических характеристиках (из описания модели)
- Особенностях конструкции протектора
- Технологиях производства (если упомянуты в описании)
- Преимуществах для разных дорожных условий
- Рекомендованных типах автомобилей
- Сезонности использования

### 2. Постобработка текста

Метод `remove_forbidden_content()` в [seo_text_generator.rb](../app/services/seo_text_generator.rb):
- Проверяет каждый параграф на наличие запрещённых слов
- Использует регулярные выражения для точного поиска
- Автоматически удаляет параграфы с запрещённым контентом
- Сохраняет правильные CTA (призывы к действию)
- Добавляет стандартный CTA если необходимо

### 3. Фиксированные варианты CTA

Только три допустимых варианта завершающего предложения:

**Русский язык:**
1. "Подобрать шины [бренд] [модель] [размер] в каталоге и оформить заказ онлайн можно на ProKoleso.ua"
2. "Выбрать и купить шины [бренд] [модель] [размер] можно в интернет-магазине ProKoleso - оформите заказ онлайн"
3. "Подберите шины [бренд] [модель] [размер] в каталоге ProKoleso и оформите заказ онлайн"

**Украинский язык:**
1. "Підібрати шини [бренд] [модель] [розмір] в каталозі та оформити замовлення онлайн можна на ProKoleso.ua"
2. "Вибрати та купити шини [бренд] [модель] [розмір] можна в інтернет-магазині ProKoleso - оформіть замовлення онлайн"
3. "Підберіть шини [бренд] [модель] [розмір] в каталозі ProKoleso та оформіть замовлення онлайн"

## Проверка работы

### Тестирование на Ruby:

```ruby
# Русский язык
test_params = {
  tire_description: "Continental ContiWinterContact TS 870 - зимние шины премиум-класса",
  brand: "Continental",
  model: "ContiWinterContact TS 870",
  season: "зимние",
  size: "205/55 R16",
  load_index: "91",
  speed_index: "H",
  product_id: "12345",
  language: "ru",
  links: []
}

generator = SeoTextGenerator.new(test_params)
result = generator.generate

# Проверяем на запрещённые слова
forbidden_words = ['доставк', 'гарант', 'акци', 'цен', 'оплат', 'консультант']
has_forbidden = forbidden_words.any? { |word| result.downcase.include?(word) }

puts has_forbidden ? "❌ Найдены запрещённые слова" : "✅ Всё чисто"
```

### Тестирование через API:

```bash
curl -X POST http://localhost:3000/api/v1/tire_seo_texts \
  -H "Content-Type: application/json" \
  -d '{
    "tire_description": "Continental ContiWinterContact TS 870 - зимние шины премиум-класса",
    "brand": "Continental",
    "model": "ContiWinterContact TS 870",
    "season": "зимние",
    "size": "205/55 R16",
    "load_index": "91",
    "speed_index": "H",
    "language": "ru"
  }'
```

## Результат

Сгенерированные SEO тексты теперь содержат:
- ✅ Только технические характеристики и особенности шин
- ✅ Информацию о конструкции и технологиях
- ✅ Рекомендации по применению
- ✅ Стандартный призыв к действию

И НЕ содержат:
- ❌ Информацию о доставке
- ❌ Гарантийные условия
- ❌ Цены и акции
- ❌ Способы оплаты
- ❌ Информацию о сервисах
