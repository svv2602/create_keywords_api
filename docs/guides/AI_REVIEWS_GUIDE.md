# Руководство по новой AI-системе генерации отзывов

## 🚀 Обзор системы

Новая система генерации отзывов объединяет существующий алгоритм с современными AI-технологиями для создания более естественных и разнообразных отзывов.

### Ключевые улучшения:
- **GPT-4o-mini** вместо GPT-3.5-turbo для лучшего качества
- **Умная постобработка** текста для естественности
- **Контекстные эмодзи** вместо случайных
- **Контроль длины** отзывов
- **Гибкие настройки** через Feature Flags

## 📋 Быстрый старт

### 1. Проверить текущий статус
```bash
rails ai_reviews:status
```

### 2. Включить AI обработку для 10% пользователей
```bash
rails ai_reviews:enable[10]
```

### 3. Протестировать систему
```bash
rails ai_reviews:test
```

## ⚙️ Управление системой

### Основные команды

```bash
# Показать статус системы
rails ai_reviews:status

# Включить AI для 25% пользователей
rails ai_reviews:enable[25]

# Отключить AI обработку
rails ai_reviews:disable

# Постепенно увеличить процент AI
rails ai_reviews:gradually_increase

# Экстренно отключить при проблемах
rails ai_reviews:emergency_disable

# Сбросить все настройки
rails ai_reviews:reset
```

### Управление компонентами

```bash
# Умные эмодзи
rails ai_reviews:enable_smart_emoji
rails ai_reviews:disable_smart_emoji

# Контроль длины
rails ai_reviews:enable_length_control
rails ai_reviews:disable_length_control
```

### Мониторинг

```bash
# Показать статистику затрат
rails ai_reviews:weekly_stats

# Показать доступные модели
rails ai_reviews:show_models
```

### Feature Flags

```ruby

FeatureFlags.enable_smart_emoji!
FeatureFlags.enable_length_control!

# Проверка настроек
FeatureFlags.use_new_ai_model?
FeatureFlags.smart_emoji_enabled?
```

## 🔄 Стратегии обработки

Система автоматически выбирает одну из трех стратегий:

### 1. AI Enhanced (Полная AI обработка)
- Используется для сложных отзывов
- Полная цепочка улучшений
- Максимальное качество

### 2. Hybrid (Гибридная)
- Комбинация старых и новых методов
- Базовая обработка + AI для проблемных случаев
- Баланс качества и скорости

### 3. Classic (Классическая)
- Существующий алгоритм без изменений
- Для простых случаев
- Максимальная скорость

## 📊 Мониторинг и метрики

### Ключевые показатели:
- **Процент AI обработки** - сколько отзывов обрабатывается через AI
- **Дневные затраты** - стоимость использования AI моделей
- **Качество отзывов** - естественность и разнообразие
- **Скорость генерации** - время обработки запросов

### Алерты:
- Превышение дневного лимита затрат
- Высокий процент ошибок AI
- Низкое качество генерируемых отзывов

## 🚨 Устранение проблем

### Частые проблемы:

1. **Превышен лимит затрат**
   ```bash
   rails ai_reviews:emergency_disable
   ```

2. **Низкое качество отзывов**
   - Проверить настройки Feature Flags
   - Снизить процент AI обработки
   - Проверить промпты в ContentWriter

3. **Медленная генерация**
   - Переключиться на более быструю модель
   - Увеличить использование гибридного режима

4. **Ошибки AI API**
   - Система автоматически переключается на fallback модель
   - Проверить логи Rails

### Логирование

Все действия логируются в Rails.logger:
```ruby
Rails.logger.info "AI processing percentage increased to 25%"
Rails.logger.warn "Daily AI cost limit exceeded: $52.30"
```

## 🔧 Настройка моделей

### Доступные модели:
- **gpt-4o-mini** - основная модель (рекомендуется)
- **gpt-4o** - для сложных задач
- **gpt-4-turbo** - максимальное качество
- **gpt-3.5-turbo** - fallback модель

### Стоимость (за 1M токенов):
- **gpt-4o-mini**: $0.15 вход / $0.6 выход
- **gpt-4o**: $5 вход / $15 выход
- **gpt-4-turbo**: $10 вход / $30 выход
- **gpt-3.5-turbo**: $0.5 вход / $1.5 выход

## 📈 Рекомендации по внедрению

## 🛡️ Безопасность и ограничения

### Автоматические ограничения:
- Дневной лимит затрат: $200 (production) / $50 (development)
- Автоматическое переключение на fallback модель при ошибках
- Экстренное отключение при превышении лимитов

### Рекомендации:
- Регулярно мониторить затраты
- Настроить алерты на превышение бюджета
- Иметь план отката к классическому алгоритму
- Периодически проверять качество отзывов
