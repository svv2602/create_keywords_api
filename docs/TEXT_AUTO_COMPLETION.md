# Автоматическое завершение обрезанных SEO-текстов

## Обзор

Система автоматического завершения обрезанных SEO-текстов предотвращает возврат неполных текстов пользователю. Если AI обрезал текст из-за лимита токенов, система автоматически дописывает недостающую часть.

## Как это работает

### 1. Проверка целостности текста

После генерации текста система проверяет его на:
- Наличие закрывающего тега `</p>`
- Наличие обязательных CTA фраз ("оформите заказ онлайн")
- Сбалансированность HTML-тегов
- Отсутствие обрезанных тегов в конце

```ruby
unless text_complete?(generated_text)
  # Текст неполный - пытаемся завершить
end
```

### 2. Анализ недостающих элементов

Система определяет, что именно отсутствует в тексте:

```ruby
missing_elements = analyze_missing_elements(truncated_text)
# => [:cta, :closing_tag, :final_paragraph]
```

Проверяемые элементы:
- `:cta` - отсутствуют CTA фразы
- `:closing_tag` - нет закрывающего `</p>`
- `:buy_phrase` - нет фраз "Купить шины..."
- `:final_paragraph` - отсутствует последний параграф

### 3. Генерация дополнения

Система создает специальный промпт для AI с просьбой завершить текст:

```ruby
completion_prompt = build_completion_prompt(truncated_text, missing_elements)
```

Промпт содержит:
- Исходный обрезанный текст
- Список недостающих элементов
- Инструкции по завершению
- Требование не дублировать существующий текст

### 4. Объединение текстов

Система умно объединяет исходный и дописанный текст:

```ruby
merged_text = merge_texts(original, completion)
```

**Логика объединения:**
1. Находит последний полный HTML-тег в исходном тексте
2. Удаляет обрезанные/незакрытые теги
3. **Удаляет неполный CTA параграф** - если в оригинале есть начало CTA ("Подобрать шины..."), но нет завершающей фразы ("оформите заказ онлайн"), весь параграф удаляется
4. **Удаляет дублирующийся текст** - проверяет, не повторяет ли дополнение последние 3-15 слов оригинала
5. Добавляет дописанный текст
6. Очищает результат от лишних пробелов

### 5. Повторная валидация

После объединения система повторно проверяет текст:

```ruby
if text_complete?(completed_text)
  # Успех! Используем завершенный текст
else
  # Не удалось завершить - возвращаем ошибку
end
```

## Примеры использования

### Пример 1: Обрезанный текст без CTA

**Исходный обрезанный текст:**
```html
<h2>Шины Michelin Pilot Sport 4</h2>
<p>Отличные характеристики сцепления. Рекомендуем выбирать разм
```

**Система анализирует:**
- Отсутствует CTA фраза ✗
- Нет закрывающего `</p>` ✗
- Обрезано слово "размер" ✗

**Система генерирует дополнение:**
```html
<p>Купить шины Michelin Pilot Sport 4 легко в каталоге ProKoleso.
Выберите подходящий размер и оформите заказ онлайн.</p>
```

**Результат после объединения:**
```html
<h2>Шины Michelin Pilot Sport 4</h2>
<p>Купить шины Michelin Pilot Sport 4 легко в каталоге ProKoleso.
Выберите подходящий размер и оформите заказ онлайн.</p>
```

### Пример 2: Незакрытый тег

**Исходный текст:**
```html
<h2>Шины для Toyota Camry</h2>
<p>Типичные размеры: 215/55R17, 215/60R16</p>
<p>Рекомендуем бренды: Michelin, Bridgestone
```

**Система обнаруживает:**
- Последний `<p>` не закрыт ✗

**Дополнение:**
```html
. Купить шины на Toyota Camry можно в ProKoleso.
Оформите заказ онлайн.</p>
```

### Пример 3: Удаление неполного CTA параграфа

**Исходный обрезанный текст:**
```html
<h2>Шины Goodyear Ultra Grip 600 195/65 R15</h2>
<p>Ключевые особенности зимних шин goodyear...</p>
<p>Подобрать шины Goodyear Ultra Grip 600 195/65 R15 в каталоге и оформить заказ онлайн можно на ProKoleso.ua</p>
```

**Система обнаруживает:**
- Есть начало CTA: "Подобрать шины..." ✓
- Есть завершающая фраза: "оформить заказ онлайн" ✓
- CTA полный - параграф НЕ удаляется ✓

**Исходный обрезанный текст с неполным CTA:**
```html
<h2>Шины Goodyear Ultra Grip 600 195/65 R15</h2>
<p>Ключевые особенности зимних шин goodyear...</p>
<p>Подобрать и купить шины GoodYear Ultra Grip 600 195/65 R15 в каталоге и оформить
```

**Система обнаруживает:**
- Есть начало CTA: "Подобрать и купить шины..." ✓
- НЕТ завершающей фразы: "оформите заказ онлайн" ✗
- **CTA неполный - параграф удаляется!** ✓

**После удаления неполного CTA:**
```html
<h2>Шины Goodyear Ultra Grip 600 195/65 R15</h2>
<p>Ключевые особенности зимних шин goodyear...</p>
```

**AI генерирует новый полный CTA:**
```html
<p>Подобрать шины Goodyear Ultra Grip 600 195/65 R15 в каталоге и оформить заказ онлайн можно на ProKoleso.ua</p>
```

**Результат - БЕЗ дублирования:**
```html
<h2>Шины Goodyear Ultra Grip 600 195/65 R15</h2>
<p>Ключевые особенности зимних шин goodyear...</p>
<p>Подобрать шины Goodyear Ultra Grip 600 195/65 R15 в каталоге и оформить заказ онлайн можно на ProKoleso.ua</p>
```

**Как это работает:**
```ruby
def remove_incomplete_cta(text)
  # Ищет начало CTA фраз: "подобрать шины", "купить шины" и т.д.
  # Проверяет наличие завершающей фразы: "оформите заказ онлайн"
  # Если CTA неполный - удаляет весь последний параграф
  # Логирует: "Removed incomplete CTA paragraph from original text"
end
```

### Пример 4: Удаление дублирующегося текста

**Исходный текст:**
```html
<p>Компанія Prokoleso пропонує шини Michelin у розмірі 265/45 R20.
Професійна консультація допомагає вибрати оптимальний варіант для
конкретного автомобіля та умов експлуатації.</p>
```

**AI сгенерировал дополнение с дублированием:**
```
та умов експлуатації. Якщо ви шукаєте надійні літні шини для
динамічної їзди, зверніть увагу на цю модель.
```

**Система обнаруживает:**
- Дублируются последние 3 слова: "та умов експлуатації" ✓
- Автоматически удаляет дублирование

**Результат после удаления дубликатов:**
```html
<p>Компанія Prokoleso пропонує шини Michelin у розмірі 265/45 R20.
Професійна консультація допомагає вибрати оптимальний варіант для
конкретного автомобіля та умов експлуатації. Якщо ви шукаєте надійні
літні шини для динамічної їзди, зверніть увагу на цю модель.</p>
```

**Как это работает:**
```ruby
def remove_duplicate_text(original, completion)
  # Извлекает последние 3-15 слов из оригинала
  # Проверяет, начинается ли дополнение с этих слов
  # Удаляет дублирующуюся часть
  # Логирует: "Removed duplicate text: 'та умов експлуатації'"
end
```

## Конфигурация

### Лимиты токенов

**SeoTextGenerator:**
```ruby
@max_tokens = params[:max_tokens] || 2000  # основной текст
completion_tokens = 800                     # дополнение
```

**CarSeoTextGenerator:**
```ruby
max_tokens = @wikipedia_info.present? ? 4500 : 3000  # основной текст
completion_tokens = 800                               # дополнение
```

### CTA фразы для разных языков

**Русский:**
- "оформите заказ онлайн"
- "заказать онлайн"
- "купить шины"
- "купить резину"

**Украинский:**
- "оформіть замовлення онлайн"
- "замовити онлайн"
- "купити шини"
- "купити резину"

## Преимущества подхода

✅ **Автоматическое восстановление** - не требует повторных запросов от пользователя
✅ **Экономия токенов** - дописывание использует всего 800 токенов вместо полной регенерации
✅ **Логичное продолжение** - AI знает контекст и продолжает мысль
✅ **Умное объединение** - корректно обрабатывает обрезанные теги и слова
✅ **Гарантия качества** - повторная валидация после завершения

## Логирование

Система подробно логирует процесс:

```
Text appears incomplete, attempting to complete it...
Attempting to complete truncated text...
Missing elements: [:cta, :closing_tag, :final_paragraph]
Text successfully completed!
```

## Обработка ошибок

Если автоматическое завершение не удалось:

```ruby
if completed_text && text_complete?(completed_text)
  # Успех
else
  Rails.logger.error "Failed to complete text - returning nil"
  return nil  # или { error: '...' }
end
```
